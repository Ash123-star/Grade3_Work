# 员工档案与合同权限规则

本页是二期成员B权限的独立维护入口。规则已由用户确认；实现验收状态见对应[OpenSpec tasks](../openspec/changes/phase2-employee-contracts/tasks.md)，不能将本页当作验收通过证明。

## 身份与入口
- 身份证仅管理员在现有后台维护，年龄由出生日期计算，不允许员工自行改写。
- 人事页面使用 `/hr`，接口使用 `/api/hr`。不向普通员工开放现有管理员后台。
- 必须为本公司ACTIVE账号且已完成初始改密；服务端每次重新检查身份及授权，不信任页面隐藏按钮或旧令牌中的权限。

## 合同与授权
- ADMIN维护本公司人员授权，可管理本公司合同；其他角色需显式READ或MANAGE授权。
- READ：查看员工最小档案、合同详情及下载附件；不能修改职责、合同或授权。
- MANAGE：READ能力加职责维护、合同归档及版本修订；不能授予自己或他人权限。
- NONE：不能访问合同列表、详情、附件或人事入口。
- 创始人、股东、合伙人、部门经理、上传者、合同所属员工均不自动获得合同权限。
- 授权以公司为边界；任何跨公司员工、合同、附件关联均不得通过。
- 版本过期返回409，写入和审计同事务；每次合同修订保留不可修改快照；附件归档后不可替换，续签材料归档为新合同，保留历史。

## 附件与敏感字段
- 合同附件为专用私有材料；不允许同时绑定任务、头像或AI材料。
- 撤销授权后，原上传者也不能继续下载已归档合同。
- 员工人事列表只提供姓名、员工ID、部门、岗位、职责及权限管理所需字段，不包含身份证原文、手机、密码或客户敏感字段。
- 合同不进入普通任务/日志或AI检索；客户字段权限须接入C/E实际契约后联合验证，不能据此宣称CRM权限已完成。

## 到期提醒
- 按北京时间日期在到期前30天、7天及到期当天扫描。
- 每份合同指定1至50名有效授权接收人，不能默认发给全体员工或全体管理层。
- 同一合同版本、节点、接收者只写入一次outbox；投递前再次检查授权。
- 通知消息不含合同正文；打开详情仍实时校验权限。撤权清除该用户已有合同通知并停止未投递消息。
- 当前为当天节点扫描；停机跨过节点不会伪报已提醒，历史补发策略尚未实现。

## 手工验收入口
1. 在隔离数据库启动带V37的后端，再以现有Vite代理方式启动web，访问 `/hr`。
2. 管理员给两个本公司有效账号分别授予READ、MANAGE。READ只能查看/下载；MANAGE可保存职责、上传专用附件归档合同，不能修改授权。
3. 指定授权接收者，合同到期日设为北京时间当天加30天、7天或当天；启用后台jobs后等待扫描与投递，或管理员调用POST `/api/hr/reminders/run`触发扫描，再由outbox投递。
4. 接收者刷新“我的合同提醒”，打开详情和历史；重复扫描不会重复发送同版本同节点通知。
5. 撤销READ/MANAGE后刷新或直接调用详情/附件接口，应403且页面清除资料；跨公司资源不可见，旧版本修订409。
