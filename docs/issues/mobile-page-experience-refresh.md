## 用户确认

- 三日仅限制首次提交；首次后24h内即使跨出三日仍可直接编辑，原submittedAt不重置。
- 手机号本人可改；电话/邮箱等向所有真实组织上级开放，同级不可凭角色猜权限。
- 公司任务保留当前授权/接收范围，完成历史不删；无任何记录才为空。统计使用多维条形/折线/扇形等可交互图。
- 审核按配置直属上级，不随机选高职级人员；无有效上级保持待审；创始人例外自动批准，不改变原有操作权限。
