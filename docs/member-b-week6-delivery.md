# week6 成员B交付与验收

关联 Issue #22，OpenSpec `member-b-week6-permissions`。基于2026-10-19抓取的main `4ded9fc`在lyb开发；未合并good。用户确认等待C提供标签及新任务审核契约，日志评论与Web任务审计由B补齐。

## 功能与边界

- 首次提交后不足24小时可以申请修订，精确边界及之后拒绝，管理员也不例外；窗口内申请可窗口外完成独立审核。撤回和重提保留首次时间，旧候选不能覆盖新版本。
- 下属日志按部门、日期、关键词查询；保留原分页并增加当前页分组、作者及部门信息，不返回他人草稿和权限外记录。
- 独立Web仅ADMIN可进入，受保护命名空间每次重新检查当前角色，撤权与停用会话被拒绝；原移动端业务权限保留。
- 评论/回复仅对已有日志读取权限的人公开，不受正文24小时限制，不可编辑删除；回复目标必须属于同一日志，通知与评论在同一事务写入。
- Web任务审计只读展示本公司事件、任务审核及最终生效，支持任务ID、分页、前后值；不会提供修改删除审计记录的入口。
- 本批没有改Flutter代码或生成新APK；Flutter展示新字段/回复交互仍需客户端成员接入。

## 数据库与启动

使用现有Java21、PostgreSQL16、Redis、Neo4j和仓库启动脚本，后端启动由Flyway自动执行V14与V15。V14允许撤回保留首次时间；V15给评论增加parent_id与同日志外键。旧已发布迁移不变；不删除日志或评论。C合并前需核对迁移编号。旧应用不能把已撤回记录的首次时间清空；回滚需评估约束和业务规则，不能直接恢复旧约束。

独立Web使用原Vite代理到后端。浏览器直连跨域时在本地配置添加实际访问Origin，不提交个人环境文件。真实联调使用本地stage测试账号，密码与环境文件不纳入Git。

验收步骤：
1. 本人提交日志，在24小时内申请修订；调整隔离测试数据至超窗，确认新申请拒绝、原申请仍可独立审批。
2. 窗口内撤回重提，确认首次时间不变；管理者不能读取撤回草稿。
3. 管理者组合部门/日期/关键词查询，确认分组、分页和范围隔离；员工不能访问下属入口。
4. 对已提交且超窗日志评论、回复，确认评论公开范围与日志一致、通知去重；空文本、超长、跨日志回复、草稿和越权请求失败且不产生通知。
5. 独立Web使用真实员工登录应拒绝，ADMIN可进入任务审计；查看、翻页、筛选记录和前后值；撤销ADMIN后接口拒绝且页面清理。

非功能验证：安全通过服务端组织/公司/草稿/角色边界测试；事务可靠性通过旧版本审批失败不覆盖正文、非法评论不写数据/outbox、回复通知去重验证。浏览器另外检查文本转义、异常/空状态及窄屏溢出。
