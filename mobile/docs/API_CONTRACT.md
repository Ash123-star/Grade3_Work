# 客户端接口接入约定

正式协议以 [后端接口](../../docs/backend-interface.md)、[OpenAPI](../../docs/openapi.json) 与对应 Controller 为准；页面映射见 [接口矩阵](api-surface-coverage.md)。本文件说明客户端接入原则，不另行维护旧阶段的接口草案和交付流水账。

## 权限与数据映射

- 页面通过 Repository 访问 HTTP；Widget 不直接解析服务端 JSON。UI 的 Record/resource/action 是客户端抽象，不能据此拼接未经定义的 REST 路径。
- 组织数据范围、注册权限、审批链和 AI 来源由服务端校验。客户端 guard 负责交互限制；待确认账号不能读取业务数据，注册不能指定管理员角色。
- 业务时区为 Asia/Shanghai，时间戳带时区；日期范围和分页按具体接口声明处理。需要完整授权列表时读取全部分页，不把首批响应当作完整组织。
- 创建和派发表单不提供完成情况。任务读取和生命周期语义按当前任务契约及对应 OpenSpec 核对，不从旧截图或旧草案补造字段。
- 任务参与人、标签、版本及候选审核响应由数据层映射。审批申请与已生效任务须区分，不能将申请 ID 当作任务 ID。

## 失败、并发与副作用

401、403、404、409、限流、超时和服务不可用均保留明确语义。版本冲突保留输入并要求核实服务端版本，不自动覆盖。跨账号或失权后的迟到响应不能恢复受保护内容。

读取重试与 SSE 重连由客户端网络层处理；写命令不得自动盲重试。需要幂等键的命令按正式接口要求提供；同载荷重试复用键，改变载荷后重新确认。SSE 通知按序号与 `Last-Event-ID` 恢复，服务端以事务 outbox 投递；AI 作业使用独立流。

附件使用受控上传/下载接口与实际附件 ID，保存成功后才显示完成；从表单移除附件不等于已从服务器删除。日志、令牌、密码、私人备注和 AI 密钥不得进入诊断输出。

## 当前实现与验收边界

[P0 状态](../../docs/mobile-p0-implementation-status.md) 和 [剩余接口状态](../../docs/mobile-remaining-api-implementation-status.md) 记录日志直改、任务区间、资料、统计、AI scope/确认版本及幂等回执等接入；详细场景保留在相关 OpenSpec 和 [接口缺口](../../docs/backend-interface-gaps.md)。意见反馈已取消，旧日志阅读登记已停用，不应根据历史草案恢复这些接口。

AI 只能通过企业服务端调用供应商；客户端的 Mock 样例不调用外部模型，也不能证明真实 AI 或数据库链路通过。建议需要人工确认，版本/范围/来源校验按服务端协议执行。

[2026-10-30 联调记录](../../docs/frontend-backend-integration-validation-2026-10-30.md) 包含当前失败与未验收范围。HTTP 夹具通过、Mock 页面通过、编译或旧批次截图都不能替代设备与真实服务验收。
