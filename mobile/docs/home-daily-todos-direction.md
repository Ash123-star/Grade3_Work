# 首页与每日事项设计方向

本文件是首页布局与交互的设计入口，关联[产品基线](../../方案.md)、[全局设计基线](tuantuan-ui-design-system.md)、[首页活动变更](../../openspec/changes/home-company-daily-todos/)和[统一验收基准](../../docs/app-requirements-acceptance.md)。本轮需求关联 Issue #94，实际验证与设备限制统一见[验证入口](../../docs/backend-validation.md)。

## 当前布局与边界

首页由欢迎区、事件纪与任务看板两张摘要、每日事项和共享五栏底栏组成。导航依次为首页、公司、日志、AI地图、我的，默认首页，兼容 `/dashboard` 与 `/view`。首页保留既有主题、素材、姓名、日期与消息入口，不显示派发按钮或占位；其他页面派发权限不变。

两张摘要使用现有纸张外观。记录均使用相同的两行预览高度，随文字缩放增加高度，自顶部依次排列；每项前置6dp深棕色（`#5D4037`）实心圆点。事件纪最多两条、任务看板最多三条，保留查看全部及记录详情。预览可以省略长文本，详情保留全文；窄屏和大字号时纵向排列，不缩小字号强塞。

## 月历复用

每日事项直接使用公司页的 `CalendarContent` 月视图，只传入个人事项数据源和独立选日状态。不再维护独立的首页月历、年月滚轮或月历下方常驻日清单。月份滚动、日期单元格、跨日记录、五行折叠、点按日期弹层、长按日期新建、长按记录拖动、跨月拖动、移动预览以及无障碍移动入口都沿用共享组件。

`TodoCalendarSource` 将本人事项的开始日、结束日和颜色映射为月历记录，打开记录仍使用既有个人事项编辑器。日期按上海自然日映射为00:00至23:59:59，拖动保持原跨度、颜色及完成状态。个人事项拖动直接保存，不弹确认或填写原因；公司原有提交审核行为保持。

月记录通过 `/api/personal-todos/month` 读取与该月完整周网格（含邻月）相交的全部本人事项，各项仅出现一次。完整分页检测数量、重复ID和游标变化，必要时重读一次，失败明确显示刷新入口。原按日和计数接口保留兼容，完整契约见[事项接口](../../docs/personal-todos-interface.md)。

## 权限、状态与可靠性

- 个人事项始终仅当前员工可见，管理员和上级不能代查；不关联任务、日志或组织事项。
- 个人选日与公司、日志互相独立；换号时清空旧数据，丢弃旧响应。共享组件不改变服务端权限。
- 新增、编辑、完成/恢复、删除沿用版本与幂等保护；保存中禁止重复操作。网络结果未知保留原命令，打开事项编辑器继续确认；冲突不能自动覆盖。
- 摘要与月历分别展示加载、空、失败及重试；失败不伪装成空或已同步。已有事项的完成、删除和备注仍由原编辑器处理。
- 胶囊、颜色、布局与手势由公司月历统一维护，不复制UI分支；小屏、大字号、键盘、跨月和账号隔离纳入回归。真机和TalkBack的验收结论单独记录，不能以组件测试代替。

## 历史原型与素材

[home-daily-todos.html](../prototypes/home-daily-todos.html)保存2026-11-05的历史方案，包含独立月历与日清单，只供回溯，不再作为当前月历实现依据。2026-11-06统一奶油黄主题以[全局设计基线](tuantuan-ui-design-system.md)与[奶油黄原型](../prototypes/sunshine-workspace.html)为准；本轮直接复用现有组件，不新增图片或全局主题。

现有素材、字体和许可证继续由各manifest及[移动端文档](README.md)维护。过程截图放Git忽略的 `output/home-prototype/`，不作为版本化产品资产；旧原型检查和历史构建结果不能继承为本批验收通过。

验收反馈调整：摘要“查看全部”固定右下角，首页提供快速日期跳转；日期/时间统一采用同一自定义面板直接输入与点选。节假日静默加载；公司排期结果用底部暖黄色短提示，不占用月历顶部。个人拖动直接保存，保留版本与幂等恢复。
