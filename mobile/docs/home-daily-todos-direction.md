# 首页与每日事项设计方向

2026-11-06 视觉覆盖：用户已授权统一奶油黄卡通主题；本页的布局、个人事项权限和业务行为继续有效，旧橙绿配色、柴犬和素材保留要求由[全局设计基线](tuantuan-ui-design-system.md)及[奶油黄原型](../prototypes/sunshine-workspace.html)替代。


本文件是首页布局、视觉参数及原型的唯一设计入口，关联 [产品基线](../../方案.md)、[团团主题](tuantuan-ui-design-system.md)、[首页活动变更](../../openspec/changes/home-company-daily-todos/) 和 [统一验收基准](../../docs/app-requirements-acceptance.md)。索引见 [移动端文档](README.md)。

**当前状态（2026-11-05）：用户已确认当前 HTML 原型，Flutter 复刻实施中。** 两张摘要统一低饱和灰米纸信纸背景，使用细横线和小折角；事件纪、任务看板和每日事项标题左侧统一使用现有柴犬头像；首页移除派发按钮与占位。实施范围为首页、事项展示与编辑器、首页语义主题及共享底栏，复用真实接口、权限、分页、幂等与冲突恢复；不改后端、数据库或其他页面内容。原型的评审工具、演示姓名/记录及浏览器外框不进入 App；问候姓名、日期、消息状态和事项均使用真实会话/业务数据。验证前不视为已交付。

## 1. 事实、目标和边界

当前 Flutter 首页由 `DashboardPage`、`HomeSummaryCard`、`DailyTodosSection` 组合，路由 `/dashboard`；两类摘要来自 `dashboard/company`、`tasks/received-card`，个人事项使用既有 todo providers 和 repository。页面框架、字体、卡通素材及底栏使用现有团团体系。

现有页面同时堆叠背景插画、角色、彩色卡片、多个大圆角容器和强调按钮；同一屏的多个装饰焦点削弱了内容主次。本提案延续小狗、奶油纸面、橙色、薄荷绿、暖米纸和圆润字体，用统一尺寸、留白及完整的日程纸页建立层级。审美好坏需用户评审，原型验证只证明布局与交互可操作。

| 不变的需求 | 设计落点 / 验收映射 |
| --- | --- |
| 首页、公司、日志、AI地图、我的，默认首页 | 五栏固定顺序，旧路由不变；H01 |
| 首页没有个人十大任务、个人重点、个人日志 | 不新增这些区块，也不删除其他页面的数据；H02 |
| 上方事件纪、任务看板紧凑摘要 | 两张便签各两条预览；卡片、标题和查看全部进完整列表，记录进详情，禁止双重跳转；H03/H04 |
| 所有执行人看到被派发任务 | 沿用 received-card 的本人参与范围和完整列表分页，不添加十条上限；H05/H06 |
| 每日事项独立、私人、采用月视图 | 月历选日与当天清单放在同一纸页，不与公司选日、任务或日志关联；T01/T03/T04 |
| 事项的既有完整操作与失败规则 | 新增、编辑、改日期、完成/恢复、取消/确认删除，保存失败/冲突保留输入；T02/T05/T06 |
| 派发资格与私人事项权限分离 | 保留明确的新增事项入口；按最新评审移除首页派发按钮，其他现有派发入口及权限不变；T07 |

不增加业绩数字、完成率图表、快捷功能宫格、AI推荐、任务状态推断或新的业务字段。上方内容继续只读，维护和审批沿用原入口。待确认账号仍由真实会话与服务端权限限制，HTML 不模拟安全保证。

## 2. 布局与路线取舍

推荐 **小狗欢迎区 → 两张轻便签 → 一张日程纸页 → 五栏底部导航**。内容纵向滚动，底栏固定。六周月历和长清单允许跨屏，不通过缩小正文或隐藏一周换取首屏塞满。

1. 欢迎区：52dp 小狗放左侧；右侧“你好，姓名”及真实日期；消息按钮靠右。省去重复的鼓励副标题，小狗作为装饰而非用户头像或完成状态。
2. 公司摘要：事件纪和任务看板统一低饱和灰米纸背景，细横线与右上小折角表达手账便签感，取消大面积纹理与渐变，标题、两条预览和查看全部按同一基线排列。正常字号并排，内容宽度小于320dp或字号超过1.3倍时转纵向；高度由内容决定，不强压长中文。
3. 每日事项：标题左侧搭配24×24柴犬头像，标题放左，新增事项在右；下方左对齐可点击年月（打开1900–2100年的年月滚轮，确认后切换至所选月1日，取消不变）、上月/今天/下月；删除月历右下方独立日期入口，周一开始的完整七列月历。日历与选中日列表共享纸页轮廓，以细分隔线衔接，不再套多层卡片。
4. 当天清单：整行正文可编辑，左侧独立完成按钮，右侧更多入口；备注按需显示，已完成使用勾选、划线与文字分组共同表达。长内容换行，内容量增加时高度自然增长，保留完整分页入口。
5. 派发入口：按最新用户评审从首页删除按钮、标签、资格开关和占位区，让出空间给月历与清单；不改变其他页面的派发流程。
6. 底栏：保留现有五个卡通图标及名称，选中背景只围绕图标，减少整块彩色底的面积；导航区为共享组件，实施时不得只为首页随意改变其他页面。

| 路线 | 兼容性、代价与取舍 |
| --- | --- |
| 只降饱和度、保留现有层层卡片 | 兼容成本低，但月历与清单仍割裂，无法解决布局问题，未选 |
| 卡通主题 + 紧凑便签 + 完整日程纸页 | 推荐；复用现有图标与业务组件，只重排表现层，无新框架、接口、迁移；需要补做 Flutter 设备验收 |
| 换成极简商务主题或信息大看板 | 与用户保留原有卡通主题的明确要求不符，撤回；不实施 |

## 3. 组件参数

以下为 Flutter 实施目标，单位为 dp/sp；原型 CSS 对应同等视觉比例。尺寸优先用下限及自然增长，禁止固定高度裁掉中文。原型的手机外框和左侧设计说明不是 App UI。

| 组件 | 参数 |
| --- | --- |
| 页面 | 默认左右16；窄屏左右10–12；垂直区块间距24；小间距4/8/12 |
| 欢迎区 | 顶部24、底部18；角色52×52；角色与文字12；消息按钮48×48、圆角17 |
| 标题与正文 | 欢迎标题25；区块标题18；摘要标题16；列表正文15、行高1.55–1.65；辅助文字12；仅计数、图例及导航允许10–11，均需语义标签和字号缩放 |
| 公司摘要 | 间距10；圆角18；描边1；内边距12；标题行48、左侧柴犬头像24×24；每条预览最小48，正常字号最多两行后进入详情；查看全部触控高度48 |
| 日程纸页 | 圆角20；描边1；内边距14；两枚装订环各7×13，仅作非交互装饰；内部只使用分隔线 |
| 月历 | 工具栏最小48；周标题11；每日期格高度48、放大字号60；日期14；选中底30×29、圆角10；未完成数10，完成用✓；保留明确的今天描边与日期语义 |
| 日期触控 | 七列均分可用宽度，整格可点，不在数字下重复嵌套小按钮。窄屏格宽会小于48，不能虚报48×48；年月标题保持至少48高的触控入口；日由月历选取，年月通过标题选择 |
| 事项行 | 最小64，纵向内边距8；完成按钮与更多按钮各48×48；可见勾选框20×20、圆角7；正文自然换行；备注为空不留空行 |
| 首页派发入口 | 按已确认原型移除，连同操作区占位一起删除 |
| 底部导航 | 约74加系统安全区；图标25–26；选中托盘46×32、圆角14；五个目标均不小于48高 |
| 弹层和动效 | 弹层圆角22、边距22，键盘避让并可滚动；按压100–120ms、选日120ms、弹层180–200ms；无循环背景动画，减少动态效果时关闭非必要动画 |

小屏/大字号优先改为纵向、折行和滚动，不缩小关键字号。标题不能强制手工换行，也不假设账号姓名长度固定。原型只使用一组代表性中文，真实姓名及极长输入仍需 Flutter 验收。

## 4. 配色和装饰

保留现有卡通色系，以下为已确认首页语义色；通过现有 `ColorScheme` 与 `ThemeExtension` 集中映射，统一管理；以首页局部主题应用，其他页面内容主题不变，共享底栏采用同一参数。

| 语义 | 色值 | 使用位置 |
| --- | --- | --- |
| 奶油背景 | `#FFF9EF` | 页面大面积底色 |
| 暖白纸面 | `#FFFEFA` | 每日事项、编辑器 |
| 橙色强调 | `#F3A45D`，前景 `#44210D` | 选中日期、保存 |
| 橙色辅助前景 | `#74421C` | 回到今天、小型提示 |
| 薄荷浅底 / 深绿文字 | `#E9F2E7` / `#32694D` | 完成勾选、新增事项及轻反馈 |
| 暖米纸 | `#F4F1E9` | 事件纪与任务看板统一信纸底，细横线`#E5DFD3`、小折角`#ECE7DB` |
| 正文 / 辅助文字 | `#3E4941` / `#687268` | 内容、日期和辅助说明 |
| 非交互边界 | `#E9DFCF` | 纸页与分隔线；不能单独承担表单识别 |
| 错误 | `#A53E3B` | 失败说明，必须同时有文字与重试入口 |

装饰预算：欢迎区一只小狗；事件纪、任务看板和每日事项标题左侧复用现有柴犬头像；底栏保留原有图标；纸页顶部两枚低对比装订环。背景不再叠加多角大插画和多张角色贴纸，避免挤占内容。摘要使用低饱和纸色、细横线和小折角，不加高饱和彩色渐变或大面积投影，纸页仅向下3–4dp的极浅垫纸阴影；角色不悬浮循环、不覆盖文字。圆润展示字体只用于标题，正文使用系统中文字体。

现有素材来源和许可记录继续由 [团团主题](tuantuan-ui-design-system.md) 及 `assets/generated_ui/dog/manifest.json`、对应素材 manifest 维护。保留小狗、业务图标和字体原文件及署名，不引入新图片、不新增外部资源或竞争产品素材。本轮没有重新生成角色或图标。

## 5. 交互、状态与实施约束

- 摘要、月历和清单分别处理加载、空数据、失败及重试；失败不得写成“暂无”。上方失败不能清空个人事项，事项失败也不遮挡摘要。
- 保存中禁重复提交；结果待确认、离线和409冲突保留原输入及原操作键；不因视觉重构改变现有版本、重试和会话隔离逻辑。
- 事项完成同时改变勾选、划线及“已完成”分组，不能只变浅颜色；选中日期有语义选中状态，今天有独立文字或语义说明。
- 切月、跨年、邻月、上海自然日、月内计数、已完成统计和公司选日隔离均沿用原实现。公司任务五行折叠不套到私人事项列表。
- 摘要中的记录点按与卡片点按必须独立，空摘要仍可进入完整列表。后续分页失败不能假称已完整。
- Flutter 实施建议新增首页专用语义 token 扩展或现有扩展字段，再迁移首页表现层；保留 Riverpod、repository、会话校验、命令及路由。共享底栏只在同一批准批次统一处理并回归五页；不把全局主题改动混入单页修复。
- 上一批验收修复仍在当前 `fix/53-app-acceptance-alignment` 工作区中；本轮不覆盖这些修改。实施前核对真实 Git 差异及既有 Issue/活动 change，复用原任务，不新建同主题文档或 OpenSpec。

## 6. 原型、验证和待评审项

原型为 [home-daily-todos.html](../prototypes/home-daily-todos.html)，直接打开或使用本地静态服务，无构建工具及第三方网络依赖。顶部“首页设计提案”设置属于评审工具，不进入正式 App；可切换事项/摘要状态、320/360/390/412宽度和1.5倍字号。

样例日期固定2026-11-05，全部事项为内存数据，刷新还原；公司内容、消息及跨页面导航仅演示入口，不假装连接真实业务服务。支持真实原型交互：选日、切月、回今天、新增/编辑/改日期、完成/恢复、确认删除、保存冲突保留输入、记录详情与完整示例列表。

2026-11-05 本地浏览器检查：320/360/390/412候选宽度 × 正常/1.5倍字体八组，内容无横向溢出、素材无缺失；新增→完成→恢复→跨年编辑、摘要记录详情、12项示例完整列表及独立状态切换已检查。原型检查证据存放 Git 忽略目录 `output/home-prototype/`。这些检查不能替代 Flutter 或服务端验收。

| 实施后的验收项 | 证据要求 |
| --- | --- |
| 主题保真 | 原小狗、卡通图标、圆润标题、奶油橙绿主题保留，按提案截图逐区比较；由用户评审 |
| 需求保真 | 执行现有 H01–H06、T01–T07，不改变权限、分页、幂等、字段及审核规则 |
| 可用性 | 360/390/412dp、1.0/1.5字号、长中文、六周月、键盘与TalkBack；无横向溢出、操作可达、底栏不覆盖内容 |
| 状态与隐私 | 各区独立失败，冲突和断网保留输入；切号清旧数据；未经授权不能读取公司或他人私人事项 |

当前待评审的是布局、橙绿/暖米纸的面积比例、字号及装饰密度。**Flutter 复刻实施中，实际验证结论在完成验收后更新。** 2026-11-04旧原型及旧Flutter截图只代表旧批次；其历史测试结论留在Git历史和统一验证入口，不继承为本次视觉重构通过。
