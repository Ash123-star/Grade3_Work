# 桌面图标与开屏生图方向

后续用户已改为前端自行绘制开屏；以下提示词保留为历史备选，当前实现与设计以brand-splash-design.md为准。

## 图标来源与接入

来源为用户2026-10-23在会话中提供的参考PNG（1024×1024）。保留完整构图和原始文件字节，存为assets/icon_desktop.png；只缩放生成Android五档ic_launcher.png，不额外裁切、不重新描绘角色。来源记录不代表额外的权属判断。

脚本：`python mobile/tool/generate_launcher_icon.py <原始方形PNG路径>`。脚本只修改桌面源图和Android桌面位图，不修改icon_splash.png或launch_image.png。项目已有process_app_icon.py会改写开屏资源，不用于本次桌面图标更新。

## 开屏方向

参考图是明黄、白色和深灰的平面卡通，不采用此前柴犬资源作为造型依据。使用同一白色圆润角色、粗深灰描边和小爱心细节，竖屏中下部探头构图，上方留品牌文字区。用户将在外部生图AI生成图片，本次不实现新开屏动画。

## 正向提示词（配合原图作为角色参考）

为一款名为“潘多拉工作台”的移动App设计精致、简洁、具有品牌辨识度的开屏插画。竖屏9:20，建议1440×3200，满版画面，输出干净原图。严格参考上传图中的白色圆润卡通角色：保持相同脸型、五官比例、深灰粗描边、俏皮眨眼和黄色小爱心细节，不改成柴犬或其他动物。延续原图明黄色、纯白、深灰三色体系：明黄接近#FFD52B、白色#FFFFFF、深灰#333333。

背景为清爽明黄色，平整干净。白色角色从画面右下方探出，占画面下半部分约45%的面积，头部轻轻倾斜，表情友好聪明，五官完整可见。角色外轮廓延伸到右侧和底部画外，形成自然裁切；脸部关键特征放在画面中央安全区域。耳部保留原图小爱心，头旁只放两三笔短小的深灰惊喜线条。造型采用圆滑、均匀、略带手绘感的粗线条和平面色块，轮廓清晰，配色克制，有成熟移动应用的完成度。

画面上方约三分之一保持完整明黄留白，供后续App叠加名称和短标语；底部8%不放关键细节，适配系统手势区。只输出插画，不生成文字，应用名称由前端排版。整体气质轻快、亲和、有设计感，避免儿童绘本式堆砌，避免复杂办公场景。

## 负向提示词

不要手机样机、界面截图、状态栏、按钮、底部导航、进度条、二维码、水印、文字、英文字母；不要3D、拟物、毛发、写实动物、柴犬、猪、额外角色；不要渐变光球、霓虹、金属、玻璃、复杂阴影、满屏图案、复杂办公桌或文件堆；不要改变原图角色的五官与眨眼方向，不要把关键五官切出画面。

## 后续页面与动效建议（尚未实现）

- 名称“潘多拉工作台”使用深灰圆润粗体，由前端绘制，居于上部预留区；可选短句“让工作，有条有理”。
- 静态图和角色透明PNG分别输出，后续才可独立制作轻微上移、眨眼或淡入；一张平铺静态图本身不是动画。
- 建议动效约1.2秒，不循环，不为播放完毕额外阻塞启动；实际时长和启动逻辑待后续需求确认。
