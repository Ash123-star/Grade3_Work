## 2. 旧方案退出基线

旧方案的低饱和棕橙/薄荷绿、6～8dp 圆角和仅空状态人物，无法表达用户希望的动漫橙和 Q 版陪伴。只改 seedColor 会保留旧形状、灰边、页内颜色和装饰比例。

新方案同时重设品牌色/前景、辅助色分区、软圆角/下沿、角色姿态库、按下/状态反馈。旧建议不再用于实施；现有 Flutter 是待迁移代码，不在设计阶段删除。

## 3. 路线比较

| 路线 | 收益 | 限制 | 结论 |
|---|---|---|---|
| 单色橙 + 极简组件 | 品牌强、实现简单 | 人物和软形状不足，像普通橙色工具 | 不选 |
| 鲜橙 + 奶油纸张 + 彩色分区 + Q 版人物 | 满足已确定偏好，四象限与状态有识别度 | 需要角色稿、状态页、对比度控制 | 采用 |
| 全屏动漫场景 + 重动画/3D | 冲击强 | 小屏信息、包体、性能、资产成本高 | 暂不选 |

推荐 #FF8A24 + 深可可字 + 薄荷/蓝/淡紫/蜂蜜黄。按钮 18dp、普通卡 20dp、人物卡 24dp；原创 2.5 头身伙伴与欢迎、记录、来源和真实成功绑定。

## 4. 从参考到实施

1. 转成自有 Material 3 / SunnyPaperTokens。
2. 做按钮、字段、chip、导航、卡片、人物和失败恢复状态页。
3. 导图验证完整四象限，日志验证长文本与操作反馈。
4. 在 360/390dp、字体放大、减少动态效果下检查。
5. 整批实现后统一测试，不用官网截图或静态示意证明 Flutter 完成。
