# 阶段 3 重做复盘（2026-10-12）

## 已确认的错误

1. 把页面重建设计降格为旧布局上的主题迁移。导图的大图标、日志的顶部切换与正文列表、AI 的旧图标导航、我的页面的堆叠菜单、详情页的纵向操作均偏离八屏设计稿。
2. 没有建立“需求 → 设计稿区块 → Flutter 页面 → 验收证据”的逐页对应关系，通用表单和详情模板不适合连续日志文档、任务时间线和审批版本对比。
3. 沿用了阶段 2 的 flutter-ui-redesign-prototype。已有 OpenSpec，但其页面实施任务和验收范围不足；不能用主题规划代替阶段 3 独立变更。
4. 20 个测试、分析和编译只能说明相应检查通过。没有实际 Flutter 八屏截图对照，因此不能据此报告符合设计稿。
5. Mock、真实服务未接入和素材未完成的边界虽然部分写入报告，却没有成为页面级完成条件。

## 纠正方式

- 使用用户提供的两张 PNG 和对应 SVG 作为明确布局基线，颜色继续采用阳光纸张/动漫橙。
- 创建 flutter-stage3-layout-rebuild，八屏各自拥有结构验收任务；旧阶段 3 验收结论不作为本次证明。
- 保留 Riverpod、go_router、Repository/Command 和服务端权限契约；采用专用页面骨架，替换不匹配的通用模板。
- 当前批次完整实现后统一 analyze、test、Dart/Flutter 测试编译（不构建 APK）和 Flutter 实际渲染截图。失败集中修正，不在中间反复完整检查。
- 周报/月报仅按现有日报聚合浏览，不假造新接口；真实 AI 缺服务时显示待接入；草稿时间来自持久化数据，空草稿不得假装已保存。
- 工作区 HCJ 包含混合历史改动及用户图片，禁止直接自动提交。远程 gh 未安装，本地 Issue 已记录，远程关联仍未完成。
