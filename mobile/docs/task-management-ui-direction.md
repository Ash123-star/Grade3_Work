# 任务管理表格 UI 方向

## 当前需求增量（2026-11-05）

用户确认任务管理列表在开始时间前增加真实完成情况，使用服务端只读 `phase`：待接收、进行中、待验收、已验收、已归档或已撤回；缺失或未知值显示“情况未知”，未生效候选不覆盖正式流转。派发表单仍不显示、提交完成情况或替代状态字段。字段映射和兼容规则见 [接口契约](../../docs/backend-interface.md)，验收按 [统一基准A01–A03](../../docs/app-requirements-acceptance.md)；不从截止日期、备注或任一参与人反馈猜测完成。

日志页右上角移除“任务管理”快捷按钮；任务管理页面及其既有其他入口保持不变，下属日志入口继续位于日志页。

## 参考方向

参与人沿用现有AppLabelBadge胶囊，使用主题浅色背景；仍最多预览两人，其余保持+N展开及完整姓名。派发标签选择器在未选中及选中时都显示服务端color，选中态保留勾选，文字随明暗调整对比度。Material3的ChipTheme.color优先于backgroundColor/selectedColor，因此选择器显式设置WidgetStatePropertyAll颜色，并同步勾选颜色，禁止全局主题盖成白底导致浅色文字不可见。派发表单标签以图标38dp高度为最小对齐区，多行内容/附件不把字段标题顶到图标上沿。现有共用SectionHeader及其他页面标准表单继续沿用居中行与内置label布局。

本批任务管理页采用“Apple 式克制的信息层级 + 飞书多维表格式字段筛选”作为参考方向：

- 页面保留唯一顶部标题、返回、全局搜索和表格，避免重复标题、概览卡和额外工具条占用手机纵向空间。
- 表头使用轻量分隔、固定列宽和明确的触控反馈，记录区使用细网格线与紧凑行高，让表格在窄屏上保持可扫描性。
- 任务名称、标签和参与人等离散字段使用可搜索的多选候选列表；字段内任一候选值命中，不同字段继续组合过滤。
- 开始时间、截止时间和派发时间由用户手动选择日期，不用已有时间值生成候选列表；筛选按业务时区中的自然日匹配。
- 选中的候选数量显示在表头，用户不需要重新打开筛选层即可判断当前列是否生效。
- 颜色只使用既有主题角色，活动状态使用主题橙色和数量徽标，不引入新的视觉色板或第三方组件。

## 未选方案

- 未采用右侧滑出操作栏：任务表同时承载横向滚动，右滑容易与列浏览手势冲突，也会让记录操作与字段浏览混在一起。
- 未采用新增的密度切换、分段切换或批量工具栏：这些控件会扩大页面垂直占用，且不属于任务表格本批验收范围。
- 未复制飞书 Web 的高密度小字号表格：移动端需要保留可读字号、48dp 触控目标和长值展开能力。

## 数据边界

候选值仅从当前会话已授权返回的完整任务列表生成。完成情况读取现有任务接口授权投影中的只读 `phase`；派发时间读取真实 `DISPATCHED` 事件对应的 `dispatchAt`，缺失时显示未提供，不能以创建时间补造。增量字段沿用现有接口兼容规则，不扩大任务可见范围；筛选仍在客户端展示层执行，全局搜索和字段条件共同生效。


## 人员目录设计与实现（代码已接入，设备验收待完成）

创建任务的参与人选择与“我的 → 人员展示”复用[现有 HTML 原型](../prototypes/home-daily-todos.html)，通过顶部“选择参与人 / 人员展示”切换。用户已确认按原型实施 Flutter；最新补充：目录名称左侧只保留展开箭头，不使用文件夹图标；人员展示必须复用现有 `_PersonnelCard`，仅增加目录层级。

沿用柴犬卡通手账主题：奶油底、单张纸页、细连接线，部门 → 团队 → 人员在同页展开；参与人选择左侧为头像，右侧为姓名与次要信息；人员展示保留原记录条的全部信息和样式。选择模式以浅橙底和勾选提示，底部展示已选名单并支持移除、取消、确认回填；查看模式隐藏勾选，点击展示演示资料。未采用多层独立卡片或逐页钻取，以减少层级装饰和往返操作。

原型使用固定组织和人物样例；通过稳定人员 ID 区分同名人员，跨节点选择在折叠、搜索时保留；搜索展开命中路径，清空可回到浏览。停用样例不可选；空团队、空目录、无搜索结果、加载中、加载失败与重试均可演示。所有数据权限及正式接口不变，真实实现仍按服务端授权范围读取。

评审检查：展开/折叠不丢选；姓名/团队/部门搜索及清空；跨部门选择与取消/确认回填；同名人员独立选择；查看模式无勾选且支持基本资料；320/390 宽与大字体无横向溢出。截图与临时检查放忽略的 `output/home-prototype/`。

Flutter 已接入共用 `OrganizationDirectory`；参与人行左头像右姓名，人员展示复用原 `_PersonnelCard` 及资料导航。人员目录、管理分页及现有界面验收的定向回归共24项通过；最新人员目录尚未重新构建APK或完成模拟器人工签收。当前整批验证结果与限制统一见[验证入口](../../docs/backend-validation.md)，不以原型或组件测试替代设备验收。
