# 任务管理表格 UI 方向

## 参考方向

本批任务管理页采用“Apple 式克制的信息层级 + 飞书多维表格式字段筛选”作为参考方向：

- 页面保留唯一顶部标题、返回、全局搜索和表格，避免重复标题、概览卡和额外工具条占用手机纵向空间。
- 表头使用轻量分隔、固定列宽和明确的触控反馈，记录区使用细网格线与紧凑行高，让表格在窄屏上保持可扫描性。
- 任务名称、标签和参与人等离散字段使用可搜索的多选候选列表；字段内任一候选值命中，不同字段继续组合过滤。
- 开始时间、截止时间和派发时间由用户手动选择日期，不用已有时间值生成候选列表；筛选按业务时区中的自然日匹配。
- 选中的候选数量显示在表头，用户不需要重新打开筛选层即可判断当前列是否生效。
- 颜色只使用既有主题角色，活动状态使用主题橙色和数量徽标，不引入新的视觉色板或第三方组件。

## 未选方案

- 未采用右侧滑出操作栏：任务表同时承载横向滚动，右滑容易与列浏览手势冲突，也会让记录操作与字段浏览混在一起。
- 未采用新增的密度切换、分段切换或批量工具栏：这些控件会扩大页面垂直占用，且不属于任务表格本批验收范围。
- 未复制飞书 Web 的高密度小字号表格：移动端需要保留可读字号、48dp 触控目标和长值展开能力。

## 数据边界

候选值仅从当前会话已授权返回的完整任务列表生成。移动端不新增字段、不改变任务接口、不扩大任务可见范围；筛选仍在客户端展示层执行，全局搜索和字段条件共同生效。
