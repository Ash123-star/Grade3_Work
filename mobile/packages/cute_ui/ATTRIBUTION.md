# OpenMoji 素材署名

作者：HfG Schwäbisch Gmünd 和 OpenMoji contributors。
来源：https://openmoji.org/ （官网 color/svg 分发目录，下载日期 2026-09-21）。
上游项目：https://github.com/hfg-gmuend/openmoji 。
许可：Creative Commons Attribution-ShareAlike 4.0 International。
许可全文：https://creativecommons.org/licenses/by-sa/4.0/legalcode 。

本应用原样使用 1F331、1F680、1F4D2、1F4C5、1F31F、1F916 六份 SVG，未修改图形。
素材在 assets/openmoji 中本地打包；源站没有随响应固定版本号，以仓库中实际文件为交付快照。
对这些素材的后续修改需标注改动并按相同许可共享。该要求针对素材，不将自编 Flutter 组件误标为 OpenMoji 作品。
