# 阶段 3 离线设计原型

直接用浏览器打开 index.html，无安装、构建、网络或服务端依赖。

app.js/styles.css 为原创布局与固定数据演示；不写入服务端，日志输入仅当前会话保留。支持五栏、日周月、日志输入与失败重试、来源、人工确认、成员分类、审批原因，以及状态/角色/字号/宽度预览。其他辅助页仅提供设计文档契约，点击会说明未实现。

render-boards.cjs 生成 mobile/docs 下两份 SVG；可将本机 sharp 模块路径作为参数生成 PNG。画稿不是 Flutter 截图。人物为本项目原创工作伙伴草案，无竞品素材、外部热链或字体下载。Flutter 对应矢量画法见 lib/shared/sunny_widgets.dart；完整人物六姿态尚未制作。

页面正文不能把“演示提交成功”当作实际业务完成。浏览器交互与 Flutter 真机视觉验收分别记录。
