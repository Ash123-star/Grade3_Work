# 管理后台员工目录改进

## 背景与范围

P0。管理员需要按部门定位员工，并在录入时明确组和直属上级。截图中的“组织与权限管理”跳转是旧版部署入口；当前仓库后台导航已无该入口，本变更以当前源码为基线。用户随后确认 Web 管理员的员工与公司事项修改直接生效；手机端与普通员工的审核链保留。

## 验收

录入与确认待确认账号时必须选择本公司同部门的组与本公司在职直属上级；目录可按部门筛选并显示组织关系；Web 管理员修改立即生效但保留版本、组织校验和审计。无效组、跨公司上级、错误部门筛选不能泄露数据。关联 Issue [#97](https://github.com/Ash123-star/Grade3_Work/issues/97)。

## 员工只读身份资料

P1。管理员录入身份证，员工只能查看本人脱敏证件号；Web 与手机年龄均由证件按北京时间计算，无证件显示未录入，不回退旧手填年龄。管理员维护沿用 V35 列、号码校验及去重，不在员工资料接口开放写入。

本批不实现联网实名认证，不推断或批量补造历史身份证，不改变组织和任务审核政策。全仓回归暴露的旧日期/日志入口、通知事件/分组、迁移断言及手动索引测试竞态一并修正，生产业务断言不删减。

## 2026-11-21 批次
用户批准姓名规则、分别查重、精简目录及详情、地址码与手机号加强。用户已批准第4点：部门经理可选择本公司跨部门创始人或明确任职的总经理、分管副总，系统管理员身份不直接提供业务上级资格。
