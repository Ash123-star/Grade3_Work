# 设计

演示数据存储与角色会话分离，切换角色不清空业务数据。统一失效刷新使列表、详情、统计与通知反映本地操作。编辑表单读取对应业务记录，建议采用独立 source 参数回填，不将建议编号误用为任务编号。

时间视图提供日列表、周分组与月历；管理面板显示当前查看成员。任务状态驱动可用动作。审批展示候选版本及逐级处理轨迹。统计使用同一任务与日志数据计算。帮助、反馈和引导独立页面。

保留真实服务适配器，演示数据不声称实际上传、下载或调用 AI。验证包括静态分析、现有布局测试、业务链路测试、APK 构建及模拟器截图。

用户追加布局要求：导图问候下仅四个板块，每块前三条、不同标题与内容色。月视图七列大日期格内放可点击事件标签；周视图七日横向时间轴，事件正文完整展示并支持双向滚动；日视图24小时等比例坐标，依据显式 startAt/endAt 排布，重叠事件分列，无时段记录单列。

日志页追加要求：使用独立业务日期，分我的日志与下属日志；我的日志可编辑提交，下属日志按人员和某一天筛选。移除日志页日周月切换与周月报入口，视图页保持原有时间视图。

日志列表最新要求：我的与下属默认不限制日期，选定具体日期才传日期范围，清除后查询全部。日志编辑日期与可空列表筛选日期分离。
