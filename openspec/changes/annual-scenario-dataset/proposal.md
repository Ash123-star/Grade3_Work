# Proposal

## Why
P0：用户决定不用旧数据，要求按Mock风格准备6—11月错位任务和关联日志，使用简短且满足登录校验的测试凭据，并给出当前云端systemd部署的空库重建步骤。现有场景集中近一个月，不能满足需求。

## What Changes
- 显式选择annual-2026独立场景目录与历史表，仅空业务库初始化；不改已发布迁移，不覆盖旧业务。
- 21名虚构人员，18名正常人员（含隔离公司）、两名待确认、一名停用；正常人员至少5条个人任务，按入职日生成日志，未来日期只生成计划任务。
- 使用Mock五种标签配色、10条有效公司重点、错位短周期任务与跨人交接、评论、附件、审核和outbox记录。
- 云端保留systemd及原数据库实例，新建空库、配置连接、启动迁移；提供备份和切回流程。
- 短账号至少3字符、密码由环境传入且至少12字符；测试文档使用test12345678。

## Capabilities
### New Capabilities
- `annual-scenario-dataset`: 空库年度关联数据与云端切换步骤。

## Impact
仅场景bootstrap、配置、SQL和部署文档。用户随后授权将并行移动端动态标签选择器改动一并提交，关联live-task-label-selector；不含任务卡片授权范围改动，不能把换数据报告为该问题修复。负责人：当前Agent；Issue #46。沿用用户跳过运行验收要求，未验证项保留。
