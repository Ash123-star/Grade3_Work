# C-09：拖动任务条避让与周高度展开

Issue #58，P0。用户明确要求同日期范围已有任务时，拖入任务下移到空行；已确认空间不足时向下撑高该周，后续周整体下移。

范围：只改变公司月历的拖动候选排布与承载滚动布局。既有任务行保持位置，候选按完整日期区间避让，不改变时长、抓取日锚点、版本、权限或审核。取消／无效落点恢复原排布；正式数据与现有更多任务入口保持原语义。

路线：仅把浮条在屏幕上向下偏移，会使条带与日期不一致且可能遮住下一周；固定高度 PageView 内加行会裁切月底。采用稳定的原任务行分配，加独立候选行；每周按所需行数临时增加高度，由双向月份 Sliver 时间线承载可变高度月份。候选按周和月份分段绘制，不能覆盖其他条带。布局变化补偿滚动位置，保持手指对应业务日期，显示与确认使用同一快照。

验收：
- 单任务、连续多个占用行、仅区间尾部重叠、不同日期可复用同一行；排布稳定且源任务不与自身竞争。
- 跨周／跨月候选按真实日期拆段，原条不挪动；空间不足周向下增高，后续周整体下移、月底不裁切。
- 悬停时周高变化不自行改变日期，取消／无效落点恢复；普通点击、纵向滚动、翻月和辅助改期仍可用。
- 算法与 Widget 几何断言验证任意正式条带和候选不相交；Android 核心链路、分析、APK、OpenSpec 验证后更新 PR #67。
- 非功能：可靠性（稳定日期／取消无写入），可用性（小屏／大字／密集排布无裁切）；原性能和人工验收限制继续保留。
