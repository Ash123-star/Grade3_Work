# Proposal

## Why

P0 / 成员 A / 二期 / #105。运营查一个客户时需要跨商城、活动和人工记录找资料，难以区分没有记录和没有权限。先完成独立的 CRM 只读查询端，供联调时组合真实关联记录。

## What Changes

- Web `/crm` 提供客户目录、按关键词和个人/企业筛选、分页、客户详情及关联记录深链。
- 统一详情区分会员资格、权益、订单、活动和服务进度，展示服务端授权返回的字段；清楚区分未授权、未接入、空结果和失败。
- 首版只读；默认关闭，现有管理员后台与 Android 导航保持原状。B 的权限矩阵、C/D/E 的数据写入、实际接口上线和最终云端联调不在 A 当前实现内。

## Capabilities

### New Capabilities

- `crm-customer-workspace`：使用独立 Web 界面浏览授权客户及对应业务记录。

### Modified Capabilities

无。

## Impact

Web 入口、视图和只读客户端契约；不增加后端表、权限规则、外部调用或 Flyway 脚本。真实验收依赖后端成员确认协议并实现公司、数据行、字段和记录关联权限。
