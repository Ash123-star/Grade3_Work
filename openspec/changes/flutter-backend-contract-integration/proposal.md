# Flutter 后端接口契约接入

## 目标

将 Flutter 真实模式的数据访问从演示 Mock 切换为后端当前已实现的 HTTP 接口，并保留 Mock 作为显式开发模式。

## 范围

- 按后端 Controller 的实际路径、HTTP 动词、请求字段和响应字段实现 `HttpRepository`。
- 将后端蛇形字段和业务 DTO 归一化为现有页面使用的 `Record` 模型。
- 认证、任务、日志、审批、导图、个人重点、通知和组织查询接入真实请求。
- 后端没有提供完整接口的页面操作必须显式报错并记录缺口。

## 非目标

- 不新增后端接口、数据库迁移或认证策略。
- 不把旧 `docs/API_CONTRACT.md` 作为契约依据。
- 不把后端缺口用 Mock 数据伪装为成功。
