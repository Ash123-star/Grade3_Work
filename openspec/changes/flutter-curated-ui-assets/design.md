## Context
Flutter3.38.7 / Dart3.10.7；HCJ工作区已有接口缺口、日历和截图改动，全部保留。Forui0.17.0要求Flutter>=3.38.0/Dart>=3.10.0，最新版不兼容。Phosphor官方仓库API可访问，raw下载失败时使用API返回的原始base64内容。
## Goals / Non-Goals
精选图标、轻量标签、原创猫狗，主题协调、低噪声、离线资源可用。非目标：换导航、整库迁移、后端或权限变化、APK构建、删除既有OpenMoji或人物。
## Decisions
完整Forui替换增加回归与SDK升级成本；选择局部FBadge，现有Material3继续承担交互，组件适配语义主题，不使用默认黑白主题。Phosphor仅导入需要的regular/fill SVG，导航跟随IconTheme着色。徽章采用现有橙/薄荷/纸张色，不用新品牌紫色。
猫狗采用原创SVG，橙猫圆脸条纹、奶油犬垂耳围巾，在欢迎及个人装饰位置使用。用户举例的商业角色没有提供授权资产，不能声称已获得授权；本批用原创同类动物丰富页面，具体角色作为待授权资源。
Untitled UI公开许可允许FREE/PRO用于产品但限制源素材分享；Figma获取入口涉及领取流程。未取得源文件时只参考公开布局，记录未导入，不从第三方镜像冒充官方素材。无需为界面变化获取账号或采购。
依赖方向：路由/页面 → shared资产/Forui适配 → theme；无网络图片和外部运行时调用。服务端数据、错误、权限、并发版本、幂等不变。装饰排除语义并不拦截指针，按钮仍48dp，大字测试覆盖360/390dp。
## Acceptance
SVG本地加载且来源/原文许可证/版本SHA齐全；五栏点击保持原路由；标签继承橙主题；猫狗可见且不覆盖正文；无权限/失败和日期交互保留。批次后统一分析、资产/路由测试、全量Mock、实际Flutter截图、OpenSpec strict与diffcheck。真实设备和未取得资源单列。
## 本批修订
采用PokeAPI/sprites中的官方角色插画PNG作为可重复使用的卡通头像，替换自绘猫狗欢迎素材、五导航、业务入口和各页通用图标。抽象统一图标组件，功能按钮采用小型方向/操作标识叠加，保留tooltip与语义以避免角色遮蔽操作含义。卡片使用暖色细边框、轻底部阴影、圆角和周月报独立分区。保留Forui徽章；Phosphor资源仍在仓库但不再作为当前主要图标。
比较仅逐页替换与统一图标映射：选择统一适配组件加定向报告分区，覆盖多页、保持尺寸契约、便于回滚。素材使用原彩透明PNG，不重着色，橙/黄为主、蓝绿辅助；绝不使用图片替代真实用户身份头像。

## 最终用户反馈
用户拒绝网络角色风格，恢复此前Phosphor/Material图标及原创猫狗与WorkBuddy，移除角色素材执行路径。保留边框阴影和报告分区。前述角色方案是撤回记录，不作为当前实施依据。
