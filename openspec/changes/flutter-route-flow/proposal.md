# Flutter 路由与用户流程实现

## 目标

将已确认的 Flutter 阶段 1 路由和用户流程落到现有移动端路由配置中，为后续 UI 页面设计提供稳定入口。

## 范围

- 五个主导航继续使用导图、视图、日志、AI 地图、我的；
- 将视图和我的切换到 `/view`、`/me` 语义化路径；
- 将认证入口统一到 `/auth/*`；
- 增加管理者下属工作台及成员分类深链；
- 同步修正现有页面入口跳转。

## 非目标

- 不实现下属工作台分类 UI；
- 不调整主题配色和页面布局；
- 不新增后端接口或修改数据模型；
- 不保留 `/calendar`、`/profile` 旧用户路径兼容。
