## Decisions

方案 A：在旧通用卡片/表单加主题，改动小但无法表达文档编辑、优先建议、时间线和版本对比，已经证明不符合设计。

集中 ThemeExtension 提供色彩、间距和形状；公司内容只读、个人重点仅本人、派发无完成状态字段；管理入口和动作依据角色/状态，服务端继续最终鉴权。详情更多菜单收纳次级动作，日志保存及提交分离，审批自审禁用且驳回必填原因，Command 继续版本/幂等语义。

假设：周报/月报为现有日报的周期浏览/聚合，清楚标注而不伪造独立报表能力；缺草稿时显示开始填写；实时 AI 未接入时显示空态。均为可逆 UI 选择，不变更接口。

## Risks / Trade-offs

- 设计稿固定内容，实际数据/大字号会改变高度；验收比较层级、空间和构图，不要求业务文案像素相等。
- 本地 SharedPreferences 草稿仍未达到产品规划中的加密 Drift；记录隐私/退出保存限制，不宣称正式离线方案完成。
- 工作区混合历史改动，远程 gh 缺失，自动提交/推送/Issue/PR 未执行。
