# Design

## Goals / Non-Goals

真实本地服务、相关联且可讲述的虚构工作场景，覆盖正常/边界/拒绝。非目标：外部 DeepSeek/OCR 成功结果造假、生产部署、现有业务库迁移或密码明文持久自动登录。

## Decisions

用户于2026-10-29确认改用可显式启用的 Flyway 数据初始化目录，并要求可应用到实际配置指定的数据库。全 API 初始化受注册限流且不能导入历史业务时间；混入正式结构迁移会让所有部署自动产生虚构账号。本批采用独立 Flyway 实例和 `flyway_scenario_history` 记录表，主结构迁移完成后才执行 `db/scenario` 的一次性版本迁移。默认禁用，启用时必须提供至少12字符的场景密码，由现有 BCrypt 编码器生成摘要并以 placeholder 传入 SQL。种子企业、账号及对象使用固定场景前缀；预检发现命名冲突直接拒绝，不覆盖、不删除现有数据。SQL明确表示历史初始化，不伪装真实接口调用；随后用当前 HTTP API 验证真实状态流转。不恢复任何已删除日志接口，不调整限流或权限来迁就数据。

## Data and isolation

目标数据库由现有 `DB_URL/DB_USER/DB_PASSWORD` 指定，不强制另建数据库。用户尚未提供其实际开发数据库配置，本机运行验证暂使用已经创建的本地 PostgreSQL 数据库，报告必须注明，不能宣称已写入用户未提供的数据库。虚构企业分产品、研发、交付三部门，至少15名用户，覆盖 ADMIN/FOUNDER/DIRECTOR/LEADER/EMPLOYEE、待确认/停用、无可靠入职时间及新员工；以商户经营看板上线项目串联任务、日志、材料、评论、验收和延期。另一公司用于隔离负向检查。账号密码随机生成，不进入 Git 或最终文本。历史日期只在首次迁移时按上海业务日确定，重启不得漂移；关闭种子开关后正常结构迁移不受独立历史表影响。

## Verification

启动后健康、真实 Repository 当前接口路径、任务建立审核/接收/反馈/退回/验收/归档/撤回、日志三日/24h/评论/草稿私密、管理员确认与直属单级、自审/旧版/跨公司拒绝、统计和导出范围、附件字节、通知 outbox、Android登录后进程停止重启和一周期限。所有请求记录不含token/密码，输出可复现汇总；有供应商/设备限制时明确保留。数据库计数/外键与时间、状态链核对。

## Risks

合成数据只是可信演示，不声称真实企业或真实个人。相对日期以运行时上海业务日生成。启动默认8080，已有本轮自有进程可替换，其他用户进程不停止。开发HTTP仅debug包允许；正式包使用HTTPS。
