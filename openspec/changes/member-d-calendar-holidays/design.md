# Design
采用服务端聚合 NateScarlet/holiday-cn（MIT、保留国务院公告来源），不让各客户端直连第三方或内置推算假期。与直接抓取政府 HTML 相比，JSON 结构稳定且可严格校验。年度内存缓存24小时，失败重试间隔5分钟；保留最后成功数据，标注 STALE；无数据返回 UNAVAILABLE。重启可重新拉取，不新增数据库依赖。固定上游地址、不接受用户 URL；超时与响应大小受限。查询同时考虑下一公告年份对12月日期影响。客户端节假日独立异步加载，失败只提示，不阻塞任务。
保留现有跨周任务条；全部正式任务与候选共同决定周高，替代早期五行折叠；小屏采用月份单一纵向滚动，不嵌套日格纵滑。
# Scope
中国大陆法定假日和调休工作日；不提供其他地区、节气、拖动或审核变更。
