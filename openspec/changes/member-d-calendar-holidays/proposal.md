# Why
成员 D 需交付完整任务行月历、相邻月份与中国大陆真实节假日。
# What Changes
- 五条完整显示，超五条显示四条及剩余数；完整日清单。
- 相邻月份可读可点击；客户端离线计算八种节日本日，仅当天显示名称，无星标，不重复标连休及补班。
- 联网复用服务端可信年度放假JSON接口显示独立休/班标记并持久缓存，断网保留缓存及离线节日本日；节日名称不再依赖放假区间的name。
# Impact
Flutter 月历、独立 calendar 后端模块和接口文档；不修改审核或已发布迁移。

# User Stories and Acceptance
- P1（原优先级；本轮列为发布必验）：用户在月历查看每日任务；范围为0/5/6/多条、相邻月份及跨年；2026-11-05用户确认恢复五行折叠，超过五项为前四项及剩余数，完整日期清单仍包含全部授权任务；空列表正常，不改变任务本身。旧完整行证据不证明本次目标通过。
- P1：用户断网查看节日本日；验收1900–2100年公历/农历/清明、除夕、跨年、同日重合、无星标、不在连休/补班重复；越界明确提示，不阻塞任务。正式放假调休不能由算法推定。
- P1：修复用户要求的全仓回归；保留当前main单次直属审核/创始人免审和参与人契约，更新旧夹具；修复AI失败终态恢复、组织汇总重复扫描、历史日志标题混用当前正文、OpenAPI字典克隆及测试执行模式。不改历史迁移或放宽权限。
- 非目标：任务拖动、标签模型、多创始人审核、真实手机/SSE/模型效果全链路验收。
