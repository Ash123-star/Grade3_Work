# Context

HCJ 工作区仅有不相关的未跟踪 `.diagnostics/`。用户确认同级内容和底部五栏均支持滑动。现有 go_router StatefulShellRoute 保存分支状态；月历固定三轨道并缩字。

# Decisions

复用现有 goBranch/provider/页面状态，新增共享横滑组件。相比替换为 PageView，保留路由恢复、权限、滚动状态，迁移小、可单独回滚；不增加动画容器和后台请求。内部手势优先消费，无法切换时向外层委托。向左为下一项，向右为上一项，末端不循环；屏幕左右24dp保留系统返回，键盘展开、弹窗覆盖、多指操作不导航。横向滚动与交互图由子组件优先处理。

月历字号13dp、行高1.15，去掉 FittedBox 与四字截断。轨道高度随字体缩放，固定2dp间距。首条保留原有日期头及8dp下移，按剩余整格高度计算0–3条容量；不扩大格子，极窄屏或大字无法容纳时不压缩文字。标题单行省略，跨日轨道连续，日期弹层仍展示全部记录。低风险假设：可读性优先于同时预览三条；容量可在后续视觉验收中调整。

所有角色复用既有数据权限；下属日志仅管理者能滑入，成员分类复用原路由授权。无新实体、接口、事务、重试或错误模型。空/加载/错误页面可切换，不改业务状态；详情/编辑保留返回和输入。

# Acceptance

- 月历4–6周、小屏、长标题及放大字体：外部尺寸不变、无缩字、无溢出；点日期完整查看；跨周轨道稳定。
- 五栏顺序不变且保持状态；日周月、三类任务、日志、AI三标签及成员分类左右切换与按钮一致。
- 短拖、纵滑、多指、屏幕边缘、输入中和弹窗不触发导航；员工无法滑入下属日志；边界不循环。
- 可用性（字号、原有点击入口）与可靠性（单次拖动一次切换、保留路由状态）需运行态验收。
- 按用户限制仅执行 OpenSpec strict、受影响文件 Dart analyze、git diff --check；设备、测试和构建不执行，运行态条目保留待验收。

# 2026-10-23 下属工作台黑边修订

根因：SiblingSwipe只平移一个页面，滑出后才更新路由并滑入下一页，空出的区域没有绘制相邻内容。以纯色遮盖能隐藏黑边，但保留了空档和两段转场，因此不采用。下属工作台改用受现有手势保护的原生PageView，直接驱动ScrollPosition，交给分页物理处理跟手、速度与吸附；相邻分类在同一视口连续布局，底层保留原卡通背景。懒构建分类并保留已访问页面状态，不一次请求所有分类。滚动停止后才同步原分类路由，点击分类反向驱动分页，避免重复导航。其他页面的旧组件本批不重构。

权限仍由既有成员Provider和服务端保证；权限失效时移除分页，不增加接口或扩大数据范围。键盘、弹窗、多指、24dp系统边缘和内部分类边界复用现有保护；减少动画时点击分类直接定位。低风险默认：保留原分类顺序、整页平移和点击入口。验收包含慢拖、短拖回弹、快速反向、多指取消、首末页、加载/错误/无权限状态及路由回退。运行态未验证，不据静态检查宣称黑边或流畅度已验收。
