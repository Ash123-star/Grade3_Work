# 设计

## 路线比较

标签可继续保留客户端固定 ID，或从已有 `GET /api/task-labels` 读取。选后者，因为服务端按公司、部门和状态校验标签，固定 ID 无法保证有效。日历任务可在客户端过滤或在已有 `participantId` 查询参数中传本人 ID；选服务端筛选，保持数据范围与分页一致。

## 数据与权限

创建仍由服务端校验派发权限、参与人、标签和幂等键。审批仍由服务端校验直属审核人、自审与 `expectedVersion`。时间线姓名通过同公司用户关联读取，仅增加展示字段；缺失姓名显示占位。任务管理继续使用服务端 `TaskAccess.scope`，日历额外限定本人参与。

## 验证与风险

针对性验证 Flutter 分析和适配测试、服务端任务测试及本地隔离 HTTP 创建与审批。当前手机 APK 版本未知，必须在安装新 APK 后重新实测五项。既有工作树改动和测试资料不纳入本变更。
