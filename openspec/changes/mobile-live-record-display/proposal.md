# 修复移动端真实记录展示

## Why

公司任务入口查询与卡片不一致，日志标题降级为日期，姓名展示存在ID回退，人员接口缺少统计导致页面伪造默认数据。关联 Issue #49，优先级P1。

## What Changes

- P1：导图公司任务与查看全部共用当前人员参与任务的分页接口，整卡与条目可点击；异常时可重试。
- P1：日志以实际工作正文首行生成摘要标题，日期保留为元数据；空正文使用“工作日志”。
- P1：任务时间线、日志作者/评论、审核与审计使用人员姓名；缺失时显示未知成员，不用登录账号或ID代替。
- P1：人员卡片使用服务端实时参与任务数、未结束任务数和上海当日日志提交状态；未知字段不显示伪造0或缺交。

## Impact

复用现有接口，添加只读统计投影与姓名字段，无数据库迁移，不改变审核权限或日志写入规则。后续用户追加：恢复视图页任务管理入口、月历仅本人任务；提交当前修改并登录云端拉取本分支重启。云端只执行必要打包，跳过测试，不做完整验收；完整验收保持待办。
