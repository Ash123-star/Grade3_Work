# Proposal

## Why

二期 E 需要把商城会员和订单接入企业协作系统，使经营概览可回查到同一授权范围内的原始订单。首版使用已确认的文件导入方案，落地可重试、可定位异常的真实数据链路。

## What Changes

- 导入商城会员和订单文件，按公司和商城外部 ID 保存快照并记录导入凭据。
- 使用 C 的显式会员绑定，把已导入记录关联到统一客户 ID。保留未匹配的商城会员供后续确认。
- 新增独立 Web 入口，供在职管理员核对会员、按状态和币种汇总原始订单金额并钻取明细。
- 优先级 P0，二期首版，成员 E 负责，关联 Issue #107。C 依赖 #104，A 的入口对接见 #105/#106。商城实时接入、正式财务口径、最终岗位权限及 A/B/D 的完整链路联验留在对应待办。

## Capabilities

### New Capabilities

- `commerce-overview` 提供商城文件导入、客户绑定查询、经营概览及订单溯源。

### Modified Capabilities

## Impact

新增 Spring Boot 商城模块、`/api/commerce`、Flyway V39 和 Vue `/commerce`；复用认证、公司隔离和 C 客户服务。同步后端接口与数据库文档、OpenAPI 快照和验证结果。
