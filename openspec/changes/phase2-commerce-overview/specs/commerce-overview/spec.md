# 商城接入与经营概览

## Purpose

将商城的外部会员及订单带入当前公司，支持重复文件导入、订单来源回查和授权后的经营核对，同时保持商城记录与公司客户主数据之间的显式绑定关系。

## ADDED Requirements

### Requirement: E01 可追溯的商城文件导入

优先级 P0。系统 SHALL 允许当前公司在职管理员上传会员与订单 JSON 快照。会员和订单分别以公司和外部 ID 唯一标识。系统 SHALL 校验同公司会员引用、订单时间、币种、金额和业务状态，并保留导入凭据及生效数据的文件行号。

#### Scenario: 导入会员和关联订单
- **WHEN** 上传含有效会员、有会员订单及访客订单的文件
- **THEN** 系统 SHALL 保存快照并返回可用于回查的导入凭据，有会员订单可按外部会员 ID 查找

#### Scenario: 数据错误可以定位
- **WHEN** 文件含非法金额、重复外部 ID 或未导入会员的引用
- **THEN** 系统 SHALL 返回出错数组、从 1 起的记录序号和字段，整批回滚

#### Scenario: 并发与历史重放
- **WHEN** 同文件重复或并发导入，或者较旧的源快照晚到
- **THEN** 系统 SHALL 对同文件返回原凭据，订单按外部 ID 只计一次，有效数据保留最新版本

#### Scenario: 同一版本的内容不一致
- **WHEN** 单条记录的源更新时间相同但内容不同，或新订单快照改变原有归属、币种或下单时间
- **THEN** 系统 MUST 返回可定位的冲突并保持整批导入前的状态

### Requirement: E02 经营概览与明细共用授权

优先级 P0。系统 SHALL 基于同一公司、日期、客户或会员、状态和币种条件查询汇总及明细。概览 SHALL 按状态和币种展示订单条数和精确原始金额合计。明细 SHALL 支持分页和导入来源回查。

#### Scenario: 钻取金额来源
- **WHEN** 管理员按上海业务日期查询并打开某个状态和币种分组
- **THEN** 系统 SHALL 返回同一范围内构成该分组的订单、外部订单 ID、原始金额及导入凭据和行号

#### Scenario: 权限不足或越权
- **WHEN** 普通员工、待确认账号或其他公司管理员尝试读取不属于其授权范围的数据
- **THEN** 系统 SHALL 拒绝业务访问，或在列表及汇总中仅返回当前公司数据，跨公司对象不得泄露存在性

### Requirement: E03 复用 C 的显式会员绑定

优先级 P0。系统 SHALL 按同公司的统一客户 ID 读取 C 已确认的商城会员绑定，允许查询该绑定下的已导入会员和订单。未绑定客户 MUST 返回空结果。导入 SHALL 保持商城外部记录独立，由 C 保存和变更客户绑定。

#### Scenario: 客户回查商城记录
- **WHEN** 管理员查询已有明确绑定的同公司客户
- **THEN** 系统 SHALL 通过该绑定返回对应会员和订单，关联生效以 C 当前绑定为准

#### Scenario: 相似身份尚未确认
- **WHEN** 客户无明确会员绑定，或不同公司使用相同外部会员 ID
- **THEN** 系统 MUST 保持客户记录隔离，未绑定客户的商城查询为空

### Requirement: E04 独立 Web 操作入口

优先级 P0。系统 SHALL 提供 `/commerce` 入口用于文件导入、会员查询和经营概览，并复用 Web 管理后台的登录、导航和视觉样式。页面 SHALL 在授权失败、文件数据错误、空结果和请求失败时提供明确反馈，支持窄屏及键盘操作。

#### Scenario: 在原有栏目与商城之间切换
- **WHEN** 管理员在后台菜单打开商城经营，或直接访问 `/commerce`
- **THEN** 系统 SHALL 显示相同的后台布局和原有栏目，管理员可使用同一会话切换到员工、公司事项、修改记录和审核

#### Scenario: 文件导入到明细
- **WHEN** 在职管理员进入商城入口导入文件并打开金额分组
- **THEN** 页面 SHALL 显示导入凭据和相同筛选下的分页订单明细

#### Scenario: 切换明细与返回全部订单
- **WHEN** 管理员打开分组、翻页或返回全部订单
- **THEN** 页面 SHALL 保留当前列表直至收到新结果，并以每页最多 10 笔展示订单，在表格上方显示结果数和多页时的页码。返回全部订单 SHALL 保留原查询条件并恢复仍有效的原页

#### Scenario: 错误或权限变化
- **WHEN** 导入文件有无效记录，或查看时会话失效
- **THEN** 页面 SHALL 显示错误位置或重新登录入口，失效会话看不到旧数据

#### Scenario: 中文展示与原编号回查
- **WHEN** 管理员浏览商城订单和会员
- **THEN** 系统 SHALL 使用中文字段、日期提示和币种名称。演示编号用可读标签展示，原编号可展开以便查询与核对
