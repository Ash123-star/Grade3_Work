# Design

## Context and decisions
当前HCJ工作区干净。可选场景V1/V2已发布，账号由users.account唯一标识登录，业务外键引用users.id。云端80端口健康检查UP，8080返回502，因此默认地址选择http://39.96.84.51/api。

直接改V1会造成已部署库校验失败；推荐追加V3，同一事务修改固定21个种子账号并撤销旧会话。只接受seedSource=flyway-scenario-v1且公司、ID匹配的场景成员；短名被其他账号占用或种子不完整时回滚。保留状态、权限、业务关联和用户版本，避免影响待审成员版本。审计记录账号变化，不记录密码或摘要。Flyway历史保证重复启动不会再次重置密码。

密码仍从SCENARIO_PASSWORD传入并BCrypt编码。用户指定简单测试密码，本批部署示例为123456；仅场景密码下限从12改为6，正式注册/改密保持原规则。禁止修改真实管理员密码。

默认云端地址仍可通过API_BASE_URL覆盖。Android全局允许HTTP会扩大影响，推荐network_security_config仅放行指定云端IP；debug保留原本地联调能力。地址是假定稳定的用户指定测试部署，后续有域名HTTPS可用覆盖参数切换。

## Acceptance
严格OpenSpec校验；场景密码边界单测；真实PostgreSQL执行V3、重复启动、账号冲突回滚、关联保持与新旧登录验证；Flutter定向配置测试、分析及APK编译；云端健康检查。无法访问云端数据库/部署时明确记录未部署，不将本地执行报告为云端生效。
