## Architecture

- `mobile/lib/theme/app_theme.dart` 承载语义颜色、圆角、阴影和动效 token。
- `mobile/lib/shared/generated_assets.dart` 统一资源路径和素材组件。
- `mobile/lib/shared/paper_layout.dart` 提供卡片、分段控件、底部操作和背景纹理容器。
- 页面只组合公共组件和业务数据，不直接解析装饰图集坐标。
- 资源使用本地 `assets/generated_ui/`，不执行网络加载。

## Asset pipeline

用户提供的 `装饰性素材.png` 是 4×4 透明图集。按网格裁成 `decorations/` 下 16 个独立 PNG，保留原始图集和原始资源目录。

业务图标、角色、背景和参考板复制到 ASCII 文件名目录，pubspec 只声明 `assets/generated_ui/`。参考板仅用于视觉对照，不进入运行时页面。

## Visual migration

- 背景：纸张纹理低透明度铺底，页面内容使用暖白和语义浅色卡片。
- 导图：四象限保留，图标改为用户提供的彩色图标，欢迎区使用困团角色和少量装饰。
- 视图：保留日/周/月业务结构，记录和日期使用圆角、胶囊和浅色分区。
- 日志：记录卡、草稿提示和底部操作使用统一代码组件。
- 组件：卡片、弹窗、底部弹层、Toast 和图表由 Flutter 构建，图片不承担文字和交互。

## Screenshot repair batch (2026-10-14)

用户已确认奶油纸张与柔和圆角方向；本批只调整 Flutter 布局和素材层。权限、数据、状态机、接口、数据库、事务、重试和 AI 服务保持既有规则；不引入依赖。图片加载失败回退代码表面，装饰 IgnorePointer/ExcludeSemantics，业务错误保留原恢复入口。

路线 A：整体卡片图片随内容拉伸，接入简单但边框/图案比例易失真，长内容和大字风险高。路线 B（采用，按用户最新反馈修订）：用户提供的无文字卡片、按钮、详情皮肤作为可见主体背景，规范化尺寸后用九宫格中心切片保持边框和装饰比例；Flutter 绘制文字、状态与点击层，代码表面作为素材缺失回退，纹理只辅助。兼容现有组件，易回滚，避免图像承载权限或内容。资源处理改为 UTF-8 安全入口和明确命名裁剪，处理棋盘底并记录源 SHA256。

月历按屏幕等分七列、不横向滚动。根据 2026-10-15 最新反馈，记录改为代码颜色标签，最多两条单行省略预览；日期与 +N 共用顶部行，减少纵向堆叠。常规单元高宽比约 1.4–1.8，大字体以可读字号计算高度、允许到 2 倍；不禁用文字缩放。点击日期查看完整记录，并保留当天完整列表和语义。标题使用随包离线圆体，正文和日期保持原字体。

允许修改：mobile/tool、generated_ui/new_pack、pubspec、主题/公共组件、dashboard/calendar/common/ai_map 的视觉代码与 UI 测试、设计/许可/验收文档，以及本变更 artifacts/本地 Issue。后端、API、数据库、密钥处理和其他用户改动不在范围。

统一验收：规划与最终 `openspec.cmd validate --all --strict`；Flutter pub get/analyze/全量 Mock 与受影响正式 HTTP 测试；资源 decode/透明边缘/裁剪范围；360/390/412dp 和 1.5 字体实际 Flutter 截图；欢迎区和更多按钮对齐、通知筛选、详情导航、月历选日和 +N；无障碍（48dp、语义、非颜色选中标记）与可靠性（无效素材路径/错误及离线保留状态）。不把 Mock 或截图称为真实后端验收。

- 用户素材的内部文字/示意图可能只是参考板，不能作为真实数据。

### 全页面覆盖与标题字体（2026-10-15 用户追加验收）

所有用户可见路由 MUST 在实际渲染中使用本地素材，包括鉴权、管理、辅助、失败与恢复页面；公共 PageFrame 提供稳定的纸张及角落层，PageBody 和组件皮肤承载内容，特殊启动/会话屏单独迁移。不能以仅登记素材路径或只覆盖首页计为完成。
标题使用 GitHub 官方来源的开源中文圆体粗字重，随应用离线打包并保留 OFL 与 SHA256；西文/数字同时使用该圆体，正文和日期保留现有系统字体。显示标题只在已有标题位置替换字体，不添加重复页名和空白头部。
比较：系统 w900 成本低但未改变字形；离线圆体成本为包体增加，能一致呈现圆角笔画并无运行时请求，因此采用离线圆体。所有页面共用背景/字体是基础覆盖，页面中的卡片、筛选、按钮、弹层必须采用对应皮肤。
允许修改扩展为所有 mobile/lib 用户界面、全路由 UI 回归测试、字体与资源登记；依旧不修改 API、业务规则、权限和数据库。统一验收额外要求路由素材审计、标题实际字体加载、真实页面截图及弹窗/底部弹层/Toast 交互回归。

## 合并维护：mobile-brand-splash

- 推荐Flutter CustomPainter搭配现有AnimationController；相较引入Lottie/Rive，不增加依赖、网络或外部资源，并能直接控制参考图的三色轮廓。用户明确授权自行设计，无未决高风险选择。
- 色值集中在开屏组件：背景#FFD52B、角色白色、线条和字#333333。不修改全局业务主题。只显示潘多拉工作台，不添加标语、按钮或伪进度。
- 竖屏标题位于中上部，角色从右下探出，自然裁切轮廓但保留五官。尺寸按可用宽高限制，窄屏长名称允许单行省略以免布局溢出。角色采用CustomPainter曲线与圆角线条，不加载旧开屏位图。
- 单次2400ms时间线：前约540ms角色轻微上移和标题淡入，中段停留，最后约384ms遮罩淡出。无额外Timer。系统减少动画时采用180ms静态快速淡化，不上移或缩放。
- 保留同一个根Stack和第一子节点的类型/位置，底层会话恢复立即开始，遮罩结束只移除叠层；底层不可交互、聚焦或被语音重复朗读，直至过渡完成。动画不等待网络，也不伪造登录成功，超时后原有恢复/错误/重试界面照常可见。
- 原生使用同色背景与静态矢量mark（早于Flutter第一帧不能执行Flutter动画）。保留原launch资源文件以便回退，不删除未使用旧素材。Android12图形区域由系统管理，其视觉衔接待设备验收。
- 默认每次进程创建播放一次，普通路由切换、返回桌面再恢复不重播；仅替换现有启动时机，低风险可逆。不扩大到全部业务路由的转场。

本节承接原小变更的有效设计，未增加业务范围。

本批补充边界：任务表、任务详情、创建任务和消息中心提供独立原型。公司月历沿用当前七列格、跨日条、五行折叠及剩余数量入口、拖动与节假日显示；不以原型示例替换实际算法。
