# 团团记账气质 Flutter UI 迁移

## Why

用户已提供按用途分类的 UI 素材包，要求将现有 Flutter 工作台从上一轮动漫橙主题迁移为成熟卡通生产力 App 的视觉系统，完整更新组件样式、页面布局和素材使用方式。

## What Changes

- 接入用户提供的角色、业务图标、背景、状态插画和装饰图集。
- 将装饰图集裁剪为可复用的独立 PNG，并登记素材来源。
- 建立团团记账气质的奶油纸张、薄荷、浅黄、珊瑚和浅蓝主题 token。
- 用 Flutter 代码统一重做卡片、弹窗、底部弹层、Toast、状态面板和图表容器。
- 更新导图、视图、日志和主导航的视觉层级，保留既有业务接口、权限和导航顺序。

## Scope

2026-10-14 继续批次：按用户九张截图修复欢迎区、四象限比例、通知选中态、详情页、月历摘要、AI 卡片和我的入口。接入 `assets/new` 的无文字局部素材；原始图保留。关联本地 Issue `docs/issues/tuantuan-ui-screenshot-repair.md`，承接阶段 3 Issue #6。

- 仅修改 mobile 资源、主题、公共组件和主页面视觉布局。
- 不新增后端接口、数据库字段、权限范围或 AI 密钥处理方式。
- 不把生成的 UI 参考图当作可交互的生产组件。
